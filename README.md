# Odonto Pequis — site (padrão AAS Premium)

Site de uma página da Odonto Pequis (Uberlândia – MG), feito pela AAS Tecnologia Editorial.

## Arquivos
- `index.html`: página
- `styles.css`: visual (cores em `:root`)
- `script.js`: número do WhatsApp e mensagens (variáveis `WHATS` e `msgs`)
- `assets/og-image.jpg`: imagem de compartilhamento (1200×630)

## Falta do cliente
- Logo, fotos (fachada, recepção, consultório, equipe) e vídeo-tour vertical
- Nome e CRO-MG do responsável técnico (rodapé), obrigatórios
- Formas de pagamento/convênios, se quiser citar
- Domínio (criar arquivo `CNAME`)
